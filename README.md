# ❤️ Heart Disease Risk Prediction Using Machine Learning and Power BI

## 📌 Project Overview

Heart disease is one of the leading causes of death worldwide. This
project builds machine learning models to predict heart disease risk
using patient medical data and presents insights through an interactive
Power BI dashboard.

## 🎯 Objectives

-   Perform data preprocessing
-   Conduct Exploratory Data Analysis (EDA)
-   Build and compare classification models
-   Evaluate model performance
-   Generate patient risk segmentation
-   Build an interactive Power BI dashboard

## 📂 Dataset

**Dataset:** Raw Merged Heart Disease Dataset

**Target Variable** - 0 → No Heart Disease - 1 → Heart Disease

## 🛠 Technologies Used

-   Python
-   Pandas
-   NumPy
-   Matplotlib
-   Seaborn
-   Scikit-learn
-   Power BI
-   Jupyter Notebook

## 📊 Workflow

Raw Dataset → Preprocessing → EDA → Feature Engineering → Machine
Learning → Evaluation → Power BI Dashboard

## 🤖 Models
